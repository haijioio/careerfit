# CareerFit V6

AI 驱动的长期职业资产与 JD 简历重构 PWA。

## V6 核心
- 上传 PDF / DOCX 简历后，AI 挖掘真实职业证据，并检查证据链缺口。
- 导入其他平台已经聊过职业/事业经历的 Markdown，对话内容先区分用户事实与 AI 分析，再提取候选证据。
- 职业证据库：场景、行为、方法/判断、结果、事实边界、证据强度、来源。
- 证据缺口：AI 生成高价值追问，用户可以直接打字或使用浏览器语音识别回答。
- AI 整理新增证据后必须经过用户确认，才会进入长期职业资产。
- JD 分析与简历重构继续沿用 V5.5 的能力迁移逻辑，并开始使用已确认的职业证据。
- 简历仍只生成 Targeted（针对性重构版）和 Keyword Focused（关键词强化版）。
- 本地优先：职业资料、职业证据、Markdown 原文、AI 配置均保存在当前浏览器；API Key 不进入职业资料 JSON 导出。

## 使用
1. 先在“设置”配置并测试一个 AI。
2. 在“职业资产”上传历史简历；成功读取后，如果当前 AI 已测试成功，会自动开始证据挖掘。
3. 也可以导入以前和 ChatGPT / Claude / Gemini 等平台聊过的职业 Markdown。
4. 到“证据库”确认候选证据，并回答 AI 发现的待完善问题。
5. 再进入“JD 分析”，用职业证据进行岗位匹配和简历重构。

## 隐私
CareerFit 本身不设置职业数据服务器。调用第三方 AI 时，对应材料会发送给你主动配置的 AI 服务商；CareerFit 不会把这些数据上传到 GitHub。
